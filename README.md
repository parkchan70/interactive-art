# 인천과학대제전 · 인공지능창작교실 — 인터랙티브 꽃잎 아트

배경을 고르고 카메라 앞에 서면, 컴퓨터가 사람의 실루엣을 알아보고
꽃잎 같은 빛 입자가 몸을 따라 흩날리는 웹 인터랙티브 아트입니다.
**`index.html` 파일 하나**로 동작하며, 설치·인터넷 연결이 필요 없습니다.

## 실행 방법

카메라(getUserMedia)는 보안 정책 때문에 `https://` 또는 `localhost`에서만 열립니다.
파일을 더블클릭해서 여는 `file://` 방식은 카메라가 차단되니 아래 중 하나를 쓰세요.

```bash
# 방법 1 — 파이썬(대부분의 PC에 이미 설치되어 있음)
python3 -m http.server 8000
#  → 브라우저에서 http://localhost:8000

# 방법 2 — Node.js
npx http-server -p 8000
```

GitHub Pages(저장소 Settings → Pages)에 올리면 https 주소가 만들어져
태블릿·휴대폰에서도 바로 열 수 있습니다.

## 조작

| 조작 | 기능 |
|---|---|
| 화면 아래 카드 / `1` `2` `3` | 배경 전환 (국화 꽃밭 · 노을 지는 해변 · 별이 빛나는 밤) |
| `R` (또는 "배경 재설정") | 배경을 다시 학습 — **관람객이 바뀔 때마다 눌러 주세요** |
| `H` | UI를 숨겨 작품만 보이게 |
| `F` | 전체화면 |
| 사람 인식 감도 | 조명이 어두우면 낮추고, 그림자·화면 떨림이 심하면 높입니다 |
| 입자 수 | 노트북이 버벅이면 500 이하로 낮춥니다 |

카메라가 없거나 권한을 거부한 경우 "카메라 없이 체험"을 누르면
마우스·손가락 위치가 사람 대신 작동합니다(전시 리허설·발표용).

## 작동 원리 (수업에서 설명할 때)

1. **웹캠 → 저해상도 축소** : 160×120 정도로 줄여 계산량을 1/30로 낮춥니다.
2. **배경 학습(background model)** : 처음 45프레임 동안 "사람이 없는 장면"의
   밝기를 기억합니다.
3. **배경 차분(background subtraction)** : 지금 화면과 기억한 배경의 밝기 차이가
   기준값보다 크면 "사람"으로 판단 → 실루엣 마스크가 만들어집니다.
   동시에 직전 프레임과의 차이로 **움직임의 세기**도 구합니다.
4. **힘의 장(force field)** : 마스크를 80×60 격자로 줄이고 블러를 준 뒤
   기울기(gradient)를 계산합니다. 기울기의 반대 방향 = "몸 바깥으로 밀려나는 힘",
   기울기의 수직 방향 = "몸을 감아 도는 소용돌이".
5. **입자 물리** : 꽃잎마다 중력 + 흔들리는 바람 + 위의 두 힘을 더해 움직이고,
   크게 움직인 자리에서는 꽃잎이 터져 나옵니다(입자 총량은 유지되어 성능이 일정).

무거운 AI 모델(MediaPipe·TensorFlow) 없이 **고전 컴퓨터비전 기법**만 써서
저사양 노트북에서도 60fps가 나오고, 오프라인에서도 동작하는 것이 핵심입니다.
"AI가 사람을 알아본다는 건 결국 이런 계산"이라는 설명으로 이어가기 좋습니다.

## 배경 추가하기

`index.html` 안 `THEMES` 배열에 객체 하나를 더 넣으면 됩니다. 이미지 파일이 아니라
`paint(ctx, W, H)` 함수로 **코드로 그리는 방식**이라 저작권 걱정이 없고,
해상도가 달라져도 항상 선명합니다.

```js
{
  id:'ocean', name:'깊은 바다',
  colors:['#dffcff','#7fe3ff','#2aa7d8'],   // 입자 색
  shape:'spark',                            // 'petal' | 'spark' | 'star'
  blend:'lighter',                          // 밝은 배경이면 'source-over'
  glow:[120,220,255], glowAmt:0.5,          // 실루엣 빛 색·세기
  gravity:6, wind:20, swirl:1.4, drag:0.99, size:[6,14], burst:160,
  paint(g, W, H){ /* 배경 그리기 */ },
  over(g, W, H, t){ /* 매 프레임 얹는 애니메이션 (없으면 빈 함수) */ }
}
```

## 부스 운영 팁

- **조명이 가장 중요합니다.** 사람 뒤 배경은 단순한 벽이 좋고, 카메라가 창문(역광)을
  향하지 않게 두세요. 조명이 바뀌면 `R`로 다시 학습시킵니다.
- 관람객이 서는 위치에 발자국 스티커를 붙여 두면 인식이 안정적입니다.
- 프로젝터를 쓰면 화면 빛이 사람에게 반사되어 인식이 흔들릴 수 있습니다.
  감도를 조금 높이거나, 카메라를 스크린 반대편에 두세요.
- 관람객 회전이 빠르면 `H`로 UI를 감춰 작품만 보이게 하고, 진행자는 단축키로 조작합니다.

## 더 해볼 만한 확장

- **사진 저장** : 캔버스를 합성해 PNG로 내려받고 QR로 가져가게 하기
- **소리** : 움직임 세기를 볼륨/음높이에 연결(Web Audio API)해 몸으로 연주하기
- **여러 명 인식** : 마스크를 덩어리(blob) 단위로 나눠 사람마다 다른 색 꽃잎 주기
- **손 모양 인식** : MediaPipe Hands를 얹어 손을 펴면 꽃잎이 모이게 하기
- **관람객이 만든 배경** : 학생이 그린 그림을 배경으로 올리는 업로드 기능
